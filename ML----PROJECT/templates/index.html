Key Factors Influencing Indian House Prices

Feature importances learned by the trained Gradient Boosting Regressor on real Indian property metrics:

Student Guide: What Drives Indian Property Prices?

1. Location Tier (Metro vs Village)

Metro IT hubs like Mumbai Bandra or Bengaluru Indiranagar command ₹1.2L–₹3.2L per Sq.Yard, while agricultural villages range from ₹9,000–₹14,000 per Sq.Yard.

2. Area in Square Yards (Gaj)

Standard plot sizes in India (100 Gaj, 200 Gaj, 300 Gaj) define the base land cost before construction.

3. Property Condition & Furnishing

Fully furnished renovated houses or luxury villas command 25%–55% higher values over standard or fixer-upper units.

4. Covered Parking & Age

In congested Indian cities, dedicated covered parking garages add significant market value and buyer liquidity.

Evaluation Metrics Guide

MAE (Mean Absolute Error)

Average absolute difference between predicted and actual house prices in ₹ INR.

RMSE (Root Mean Squared Error)

Standard deviation of prediction residuals, penalizing larger valuation errors.

R² Score (Coefficient of Determination)

Proportion of variance explained by features (1.0 = perfect accuracy).
